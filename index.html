🤦 අපි කරන Common Mistakes

❌ “FREE” කියලා දැක්කාම ඉක්මනින් QR Code එක Scan කරනවා.

❌ QR Code එක ආවේ කොහෙන්ද කියලා බලන්නේ නැහැ.

❌ Scan කළාට පස්සේ open වෙන URL එක check කරන්නේ නැහැ.

❌ Unknown website එකකට ඉක්මනින් යනවා.

❌ “Congratulations! You Won!” වගේ messages ඉක්මනින් විශ්වාස කරනවා.

❌ Website එක Password ඉල්ලුවොත් verify නොකර enter කරන්න හදනවා.

❌ OTP / PIN වැනි sensitive information share කරනවා.

❌ Bank හෝ Card details ඉල්ලුවොත් website එක verify නොකර ලබා දෙනවා.

❌ Urgent message එකක් දැක්කාම දෙපාරක් නොහිතා action එකක් ගන්නවා.

❌ QR Code එකක් තියෙන නිසා ඒක automatically safe කියලා හිතනවා.

🛡️ QR Code එකක් Scan කිරීමට පෙර

1️⃣ STOP – දෙපාරක් හිතන්න.

2️⃣ VERIFY – QR Code එකේ source එක විශ්වාසදායකද බලන්න.

3️⃣ CHECK – Scan කිරීමෙන් පසු open වන website/domain එක carefully check කරන්න.

4️⃣ PROTECT – Password, OTP, PIN හෝ banking details ලබා නොදෙන්න.

5️⃣ REPORT – සැකයක් තිබේ නම් IT/Security team එකට report කරන්න.

🔐 මතක තියාගන්න

QR Code එකක් කියන්නේ link එකක් පමණයි.

QR Code එකක් තිබුණා කියලා ඒක automatically safe කියන guarantee එකක් නැහැ.
